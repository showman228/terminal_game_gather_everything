# Console Labyrinth Game
Это увлекательная консольная 2D-игра, в которой игрок управляет персонажем, перемещаясь по лабиринту. 

## Суть игры
Ваша главная цель — собрать **5 очков (звезд `*`)** за ограниченное время (по умолчанию 90 секунд). На вашем пути будут встречаться закрытые двери (`&`), для открытия которых необходимо собирать ключи (`?`). 

**Игровые обозначения:**
* `@` — Ваш персонаж
* `#` — Стены лабиринта (непроходимые)
* `*` — Очки (нужно собрать 5 штук для победы)
* `?` — Ключи 
* `&` — Двери (открываются на клавишу `E`, если есть ключи)

## Используемые библиотеки
В проекте используются следующие стандартные и сторонние библиотеки Python:
* **`time`**: Используется для отслеживания времени игровой сессии (таймер на 90 секунд) и создания небольших задержек (`time.sleep`) в главном цикле игры.
* **`random`**: Применяется для случайного выбора стартовой позиции игрока, а также для случайного спавна очков (звезд) и ключей на свободных клетках карты.
* **`os`**: Необходима для кроссплатформенной очистки консоли (`cls` для Windows, `clear` для Linux/Mac) перед отрисовкой новых кадров.
* **`typing` (`Tuple`, `List`)**: Используется для аннотации типов, что делает код более читаемым и понятным для разработчиков и IDE.
* **`pynput` (`keyboard`)**: Сторонняя библиотека, обеспечивающая асинхронное "прослушивание" нажатий клавиш. Позволяет управлять персонажем в реальном времени без необходимости каждый раз нажимать клавишу `Enter`.

## Описание файлов и функций

### 1. `constaints.py`
Файл конфигурации и хранения уровней. 
* Содержит константы времени: `FLAG_TIME_LIMIT` и `TIME_LIMIT` (лимит времени на игру).
* Хранит 5 различных карт лабиринтов (`GAME_MAP_1` ... `GAME_MAP_5`), представленных в виде двумерных массивов (списков).

### 2. `game_func.py`
Главный файл с игровой логикой и движком.

#### Глобальные функции:
* `print_control() -> None`: Выводит в консоль инструкцию по управлению персонажем (WASD, E, ESC).
* `clear_screen()`: Очищает экран терминала в зависимости от операционной системы пользователя.
* `print_game_map(game_map: List[List[int]]) -> None`: Форматирует и красиво выводит двумерный массив (карту) в консоль.
* `free_space_on_game_map(game_map: List[List[int]]) -> List[List[int]]`: Проходится по карте и возвращает список координат `[y, x]`, на которых находится пустое пространство (не стены `#`), чтобы там можно было размещать предметы или игрока.
* `update_cursor(x, y)`: Использует ANSI escape-коды для перемещения курсора в консоли. Это позволяет перерисовывать только изменившиеся элементы (перемещение игрока, исчезновение ключа), избегая мерцания при полной очистке экрана.
* `start_game(*args, **kwargs)`: Точка входа в игру. Реализует главное меню: предлагает выбрать одну из 5 карт, затем генерирует до 5 случайных стартовых позиций и предлагает их игроку. После подтверждения запускает сессию `GameSession`.

#### Класс `GameSession`
Отвечает за саму игровую сессию, управление состоянием и проверку условий победы/поражения.
* `__init__(self, game_map, start_x, start_y)`: Инициализирует игру. Создает копию выбранной карты, устанавливает таймеры, обнуляет счетчики очков и ключей, определяет свободные места.
* `on_press(self, key)`: Обработчик нажатий клавиш (WASD). Вычисляет новые координаты. 
  * Проверяет взаимодействие с дверями (клавиша `E` + наличие ключа).
  * Блокирует прохождение сквозь стены (`#`) и закрытые двери (`&`).
  * Обрабатывает подбор звезд (`*`) и ключей (`?`).
  * Обновляет позицию символа `@` на экране без полной перерисовки.
* `on_release(self, key)`: Обработчик отпускания клавиш. Завершает чтение клавиатуры при нажатии `ESC`.
* `update_time(self)`: Вычисляет прошедшее с начала игры время и выводит его под картой.
* `update_checkpoint(self) -> None`: Случайным образом выбирает свободную координату, удаляет её из списка свободных мест и рисует там звезду (`*`).
* `update_key(self) -> None`: Аналогично `update_checkpoint`, но спавнит ключ (`?`), следя за тем, чтобы он не появился поверх звезды или другого ключа.
* `show_points(self)`: Выводит под картой текущий счетчик собранных звезд.
* `show_keys(self)`: Выводит под картой текущий счетчик собранных ключей.
* `run(self)`: Главный игровой цикл. Инициализирует стартовые предметы (1 звезда, 2 ключа), запускает слушатель клавиатуры (`pynput`) и в цикле `while` проверяет статус игры (вышло ли время, собрано ли 5 очков), обновляя UI с частотой 0.1 сек. Завершает игру при достижении условий.
